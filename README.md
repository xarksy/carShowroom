# 🚗 showroomCar

Project Django untuk manajemen showroom mobil — pengelolaan data mobil, perhitungan hpp bank, simulasi kredit, dan layout yang rapi.

## 🚀 Fitur
- [✔️] Manajemen data mobil
- [✔️] Tampilan dashboard sederhana
- [✔️] Layout rapi dan responsif (optional)

## 🛠️ Setup

### 1. Clone project
```bash
git clone https://github.com/username/showroomCar.git
cd showroomCar

**### 2. Buat virtual environment**
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate

**### 3. Install dependencies**
pip install -r requirements.txt

**### 4. Setup environment variable**
cp .env.example .env

**### 5. Jalankan server**
python manage.py runserver
